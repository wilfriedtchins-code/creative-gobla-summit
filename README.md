
# CC Global Summit 2015

A responsive landing page for the Creative Commons Global Summit 2015. This project replicates the official CC Summit design with a focus on openness, sharing, and global collaboration.

## 🛠️ Built With
HTML, CSS and bootstrap

### Link
https://wilfriedtchins-code.github.io/creative-gobla-summit/

### Tech Stack
HTML,CSS,Bootstrap and GitHub.

**Client**
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

**Deployment**
- GitHub Pages

### Key Features
Describe between 1-3 key features of the application.
- Responsive Design: Works on mobile, tablet, and desktop
- Icon-Based Program Section: Uses Bootstrap Icons to showcase summit activities
- Brand-Aligned UI: Follows CC color palette with orange `#ec5242` and dark `#272A31` backgrounds
